Interface: IIntentIqIdProviderParams

Parameters of the intentIqId userId provider.

This entry is never authored in MoliConfig. It is assembled by the intentiq module from modules.intentiq.IntentIqModuleConfig plus runtime-derived values and merged into the prebid userSync config - see ads/modules/intentiq.

See​

  • https://github.com/prebid/Prebid.js/blob/master/modules/intentIqIdSystem.ts
  • https://docs.prebid.org/dev-docs/modules/userid-submodules/intentiq.html

Properties​

ABTestingConfigurationSource?​

readonly optional ABTestingConfigurationSource: IntentIqABConfigSource

Determines how the A/B test group is assigned. Defaults to 'IIQServer'.

abPercentage?​

readonly optional abPercentage: number

Percentage of users placed in the WITH_IIQ (group A) cohort. Accepts 0-100; values outside that range are clamped. Defaults to 95. Only used when ABTestingConfigurationSource is 'percentage' or 'IIQServer' (no prior server termination cause).

additionalParams?​

readonly optional additionalParams: object

Freeform key-value pairs appended to every pixel request.

Out of scope for v1 - never populated by moli.

Index Signature​

[key: string]: string | number | boolean

browserBlackList?​

readonly optional browserBlackList: string

Comma-separated list of browser names (lowercase) that should be excluded from identity resolution, e.g. 'chrome,safari'.

callback()?​

readonly optional callback: (data) => void

Invoked when the identity lookup completes or times out. Receives the resolved EID payload or an empty string when the browser is blacklisted or the user is opted out.

Not used by moli in v1 - always left unset.

Parameters​

• data: string | object

Returns​

void

chTimeout?​

readonly optional chTimeout: number

Timeout in milliseconds for fetching Client Hints before falling back to an empty string. Defaults to 10 ms.

Out of scope for v1 - never populated by moli.

domainName?​

readonly optional domainName: string

Publisher domain name, used to build the referrer URL parameter.

Computed at runtime by the intentiq module from adUnitPathVariables.domain - never configurable.

gamObjectReference?​

readonly optional gamObjectReference: Record<string, unknown>

Reference to the googletag object, used for automatic targeting key injection.

Computed at runtime by the intentiq module from window.googletag whenever gamParameterName is set - never configurable.

gamParameterName?​

readonly optional gamParameterName: string

GAM targeting key used to pass the A/B group. Defaults to 'intent_iq_group'.

group?​

readonly optional group: "A" | "B"

Explicit A/B group override. Only used when ABTestingConfigurationSource is 'group'.

groupChanged()?​

readonly optional groupChanged: (group, terminationCause?) => void

Called whenever the resolved A/B group changes. Receives the new group ('A' | 'B') and the server termination-cause code when available.

Not used by moli in v1 - always left unset.

Parameters​

• group: "A" | "B"

• terminationCause?: number

Returns​

void

iiqPixelServerAddress?​

readonly optional iiqPixelServerAddress: string

Override for the IntentIQ pixel/sync server base URL. Derived from region if unset.

Out of scope for v1 - never populated by moli.

iiqServerAddress?​

readonly optional iiqServerAddress: string

Override for the IntentIQ API server base URL. Derived from region if unset.

Out of scope for v1 - never populated by moli.

pai?​

readonly optional pai: string

Partner-supplied Advertiser ID.

Out of scope for v1 - never populated by moli.

partner​

readonly partner: number

Partner ID assigned by IntentIQ. Required.

partnerClientId?​

readonly optional partnerClientId: string

Partner-supplied first-party client identifier.

Out of scope for v1 - never populated by moli.

partnerClientIdType?​

readonly optional partnerClientIdType: number

Type code for partnerClientId. Must be a positive integer recognised by the IntentIQ server.

Out of scope for v1 - never populated by moli.

pcid?​

readonly optional pcid: string

Partner-supplied client identifier used internally by IntentIQ (first-party cookie id).

Out of scope for v1 - never populated by moli.

region?​

readonly optional region: string

Geo-region routing hint for the IntentIQ API/sync servers.

Always hardcoded to 'gdpr' by the intentiq module - never configurable.

siloEnabled?​

readonly optional siloEnabled: boolean

When true, first-party data is stored under a partner-specific key so multiple IntentIQ configurations on the same page do not collide.

Out of scope for v1 - never populated by moli.

sourceMetaData?​

readonly optional sourceMetaData: string

Human-readable metadata tag describing the integration source (e.g. 'prebid', 'amp'). Translated to a numeric code internally.

Out of scope for v1 - never populated by moli.

sourceMetaDataExternal?​

readonly optional sourceMetaDataExternal: number

Numeric metadata code for the integration source when a specific override is required.

Out of scope for v1 - never populated by moli.

timeoutInMillis?​

readonly optional timeoutInMillis: number

Milliseconds to wait for the server response before firing callback with whatever data is currently available. Defaults to 500 ms.

Out of scope for v1 - never populated by moli.
